# MavFix
This project is run on Node.js/React.js v24.21.0.

The database used is PostgreSQL v18.6

Currently database is ran locally, but all database information is hardcoded in database.jsx if you're trying to run the code locally with db functionality

To install react modules after Node.js has been installed run this command in the client AND server directories
```
npm install
```
To run the test server for the website and/or the database for debugging run this command
```
npm run dev
```
